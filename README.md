# Museum of the Year 3000

A museum label from the year 3000, placed beside an ordinary object from today: a QR code printed on a restaurant table.

The label, written by `main.ts` to `/output/entry.txt`:

> Table QR Code, c. 2025. Diners held up their glowing rectangles, bowed to this sacred square, and waited for food to appear.

The joke is the year-3000 misreading: the curators treat a printed QR code as a sacred square, and the phone as a glowing rectangle used in a food-summoning ritual — which is, deadpan, more or less what diners actually did.

## Run

```sh
node main.ts
```

Writes one line (under 200 characters) to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). Deterministic: no randomness, clock, network, or input.
